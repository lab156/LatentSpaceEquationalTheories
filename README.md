# The Latent Space of Equational Theories
## Important links:

* [arXiv Paper](https://arxiv.org/abs/2601.20759)
* [Project Website](https://luisberlioz.github.io/LatentSpaceEquationalTheories/)
* [Original Equational Theories site](https://teorth.github.io/equational_theories/)

## Setting Up
Create and `.env` file with the following fields.
* `IMPORTED_DATA_PATH`: where you want to store the data imported form the original equational theories project.
* `GENERATED_DATA_PATH`: path to store generated data: Stone Pairs, Implication Graphs, etc.
